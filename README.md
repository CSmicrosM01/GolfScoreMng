# 正本杯 ゴルフスコア管理Webアプリ

## 概要

年間のゴルフスコアを管理するWebアプリケーションです。S3静的ホスティングに対応し、Lambda関数URL経由で複数端末間のデータ自動同期が可能です。

**最新バージョン: v2.2.0（2026年1月9日）**
- パーオン率をPar3/Par4/Par5別に入力（楽天ゴルフスコア対応）
- 総合パーオン率の自動計算（Par3:4H, Par4:10H, Par5:4Hの重み付け平均）
- ランキング表示を1回以上の参加で表示するように変更
- デフォルトカップ名を「正本杯」に変更
- 特別賞の賞品情報追加

## プロンプト内容

### 初回プロンプト

```
年間のゴルフスコアを管理するWebアプリを作成したい。S3に静的ホスティングでDBは使用しない方式としたい。

現在は下記のエクセルで運用しているのでその運用内容から適切な画面構成としたい。
Downloads\2025松本杯.xlsx

要望としては
・ログイン時にユーザを選択（松本、正本、渡邉、近藤、比企、内藤で固定）
・ハンディキャップを適用したスコアと、適用しないスコアの両方を表示したい
・下記のルールで実施しているので、平均ベスト、ベストスコア、パター平均ベスト、ホールインワン達成者、イーグル達成者を確認できるようにしたい

　[開催・参加条件]
・ラウンド参加人数が３名以上であること
・ラウンドに３回以上参加していること

[各賞]
優勝　：翌年の○○杯に名前が付く、トロフィー授与
準優勝：６位からラウンドの昼食代を奢ってもらう ※
３位　：５位からラウンドの昼食代を奢ってもらう ※
４位　：何もなし
５位　：３位のラウンドの昼食代を奢る ※
６位　：準優勝のラウンドの昼食代を奢る ※
※：食事付いていないプランで全額

ベストスコア賞
：参加者全員から1,000円集めて6,000円ぐらいのゴルフボールをプレゼント（受賞者が好きなゴルフボールを選べる）

平均パット数ランキング１位
：参加者全員から1,000円集めて6,000円ぐらいのゴルフボールをプレゼント（受賞者が好きなゴルフボールを選べる）
※パット数はグリーン上でパットした数
※一度グリーンを出てもリセットされない
※OKもパット数に含める
```

## 機能一覧

### 1. ログイン画面
- 6名のユーザー（松本、正本、渡邉、近藤、比企、内藤）から選択
- ログインボタンは「さん」なし、それ以外の画面では「さん」付け

### 2. ダッシュボード
- ベストスコア賞（3回以上参加者のベスト）
- パット平均ベスト賞
- 開催情報（総開催回数、有効参加者数）
- ログインユーザーの個人成績
- **総合ランキング**（ハンディ適用、3回以上参加者のみ）
- ホールインワン・イーグル・**アルバトロス**達成者リスト

### 3. ランキング
- **総合順位（ネット - HC適用）**（平均スコア）
  - ハンディキャップを適用したランキング
  - 1位〜6位の賞バッジ表示
- **総合順位（グロス - HCなし）**（平均スコア）
  - ハンディキャップなしのランキング
- **ベストスコアランキング**（上位10件）
- **パット平均ランキング**
- **⭐️ パーオン率ランキング**（Par3/Par4/Par5/総合表示）
- **⭐️ 平均スコア変化ランキング**
  - 昨年度と今年度の平均スコアを比較
- ※最終順位確定は3回以上参加者が対象、1回以上で表示

### 4. スコア一覧
- 全ラウンドのスコア・パット数表示（ユーザー名は「さん」なし）
- ユーザー/コースでフィルタリング可能
- 参加人数3名未満のラウンドは薄く表示（無効扱い）
- 各ラウンドに「編集」ボタン

### 5. スコア入力（個人用）
- ログインユーザーが自分のスコアのみを簡単に入力
- スコア、パット数、**パーオン率（Par3/Par4/Par5別、%）** を入力
- 最近の自分のスコア履歴を表示
- 同じ日付・コースのラウンドがあれば自動で追加

### 6. 一括入力（幹事用）
- 全員のスコアをまとめて入力
- スコア、パット数、**パーオン率（Par3/Par4/Par5別、%）** を入力
- 既存ラウンドの編集・削除
- ホールインワン/イーグル/**アルバトロス**達成記録
- データエクスポート/インポート（JSON形式）

### 7. ハンディキャップ
- **WHS自動計算**: 直近20ラウンドのベスト8から自動算出
- **全ユーザーのHC一覧**: ハンディキャップインデックス表示
- **詳細表示**: クリックでベスト8スコア一覧を表示
- **自動更新**: スコア保存時に自動再計算
- **⭐️ 手動更新機能**（NEW: v2.1.0）: 年2回（1月・6月）にハンディキャップを固定

### 8. 各賞・ルール
- 開催・参加条件の説明
- 各順位の賞内容（**2026年度ルール更新**）
  - 1位: 6位からラウンドの昼食代をプレゼントしてもらう
  - 2位: 5位からラウンドの昼食代をプレゼントしてもらう
  - 5位: 2位にラウンドの昼食代をプレゼント
  - 6位: 1位にラウンドの昼食代をプレゼント
- パット数ルールの説明
- **⭐️ カップ名の名前権利**（NEW: v2.1.0）
  - 優先順位: ベスト更新（80未満）> アルバトロス > ホールインワン > イーグル > グロス1位
- **特別賞**
  - パーオン率ランキング1位: ご要望のゴルフボール（5,000円〜6,000円相当）
  - 平均誤差賞（最も上達した人）: ご要望のゴルフボール（5,000円〜6,000円相当）
- ハンディキャップについての説明
- **カップ名設定**（年度ごとに変更可能）

## データ同期方式

### 方式1: Lambda関数URL経由（推奨）

スコアを保存すると自動的にS3上の`data.json`に同期されます。

**設定方法**: [AWS_SETUP.md](AWS_SETUP.md) を参照

**仕組み**:
```
[端末A] ──保存──> Lambda関数URL ──> S3 data.json
                                        ↓
[端末B] ←──取得── Lambda関数URL <────────┘
```

**app.jsの設定**:
```javascript
const LAMBDA_FUNCTION_URL = 'https://xxxxxxxxxx.lambda-url.ap-northeast-1.on.aws/';
const USE_LAMBDA_SYNC = true;
```

### 方式2: 手動アップロード（シンプル）

スコア保存後、`data.json`をダウンロードしてS3に手動アップロードします。

**app.jsの設定**:
```javascript
const USE_LAMBDA_SYNC = false;
const USE_S3_SYNC = true;
```

## ルール実装詳細

### 有効ラウンド条件
- 参加人数が3名以上

### ランキング対象条件
- 有効ラウンドに3回以上参加

### ハンディキャップ（v2.1.0でさらに改善）
- **WHS（ワールドハンディキャップシステム）採用**
- 差分スコア計算式: `(スコア - コースレート) × (113 / スロープレーティング)`
- **カスタムルール**: 直近20ラウンド未満の場合は全ラウンドからベスト8を使用
- ハンディキャップインデックス = `平均差分 × 0.96`
- コースデータベース搭載（15コース登録済み）
- **手動更新機能**: 年2回（1月・6月）にハンディキャップを固定
